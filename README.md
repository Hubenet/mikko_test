Mikko Test 

Ik heb het Symfony 8 framework gebruikt. Mijn eerste keer. Symfony 6 is de laatste Symfony versie waar ik mee
gewerkt heb. De hele working environment heb ik from scratch opgezet en het draait Windows 11 Pro waarbij ik VS 
code gebruik. Om Symfony lokaal te runnen kun je een aantal opties gebruiken, ik heb gekozen voor de Ubuntu via de WSL.

Op Windows 11 is een functie waarmee je het Linux-besturingssysteem Ubuntu rechtstreeks op je Windows-computer
kunt draaien, zonder dat je een zware virtuele machine of een dubbel opstartsysteem (dual-boot) nodig hebt. 
Dit is onderdeel van het Microsoft Learn (Windows Subsystem for Linux).

Database was niet nodig voor deze opdracht en ik twijfelde of ik de controller wilde laten maken door AI of zelf.
Vanwege tijdgebrek en om aan te kunnen tonen dat ik meer dan gemiddeld vaardig ben in het gebruik van de AI tools,
heb ik de controller en de service met gemini in VS code gegenereerd en met wat kleine aanpassingen werkend
gekregen. De output is zoals beschreven in het Mikka Test Candidate Sample application.
